# Privacy policy

*Death by Slides* collects nothing.

- **No data leaves your device.** The game has no network access, no
  accounts, no advertising, no analytics and no crash reporting.
- **What stays on your device:** which slides you have won, your best time on
  each, and your settings, so you can pick up where you left off. They are
  stored only on the device, in the app's own storage, and are deleted when
  you uninstall the game.
- **Controllers** are read locally, while the game is open, and nothing about
  them is stored.
- **Children:** the game is suitable for all ages, and because it collects
  nothing it collects nothing from children either.

If this ever changes, this page will say so before the build that changes it
is released.

Questions: open an issue on the game's GitHub repository.
